# Mi primer PR

Este repositorio es un ejemplo para aprender a usar Pull Requests en GitHub. Sirve para que practiques el flujo completo: crear una rama, hacer un cambio pequeño, y fusionarlo.

## ¿Qué es un Pull Request?

Un Pull Request (PR) es una propuesta de cambios. Permite que alguien revise tu código antes de incorporarlo al proyecto principal.

## Pasos típicos

1. Crear una rama nueva.
2. Hacer un cambio.
3. Subir la rama a GitHub.
4. Abrir un Pull Request.
5. Revisar y fusionar (merge).
